All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project

## [1.0.0] - 2026-08-20

### Added

- Reproducible local and GitHub skill acquisition with content-addressed snapshots.
- Deterministic capability extraction, semantic update diff, and explainable policy engine.
- Exact-hash, expiring approval workflow with explicit critical policy overrides.
- Transactional application, lockfile drift detection, and deterministic rollback.
- Tamper-evident audit log, Markdown/JSON reports, static fixtures, and Docker sandbox fixtures.
- Cross-platform CLI, reusable GitHub Action, documentation, tests, and release automation.
