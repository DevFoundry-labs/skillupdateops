# Contributor Covenant Code of Conduct

We pledge to make participation in this project a harassment-free experience for everyone. Be
respectful, assume good intent while addressing concrete impact, and keep technical discussions
focused on the work.

Unacceptable behavior includes harassment, discrimination, threats, doxxing, sexualized attention,
and sustained disruption. Maintainers may remove, edit, or reject contributions and participation
that violate these standards.

Report conduct concerns privately through the repository owner's GitHub contact channel. Reports
will be reviewed promptly and handled with appropriate confidentiality.
